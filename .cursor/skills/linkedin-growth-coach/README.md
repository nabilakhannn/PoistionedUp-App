# LinkedIn growth coach (agent skill)

A **Cursor / Claude Code** skill that steers the model like a direct, systems-first LinkedIn operator: content packaging, ICP tiers, DMs, engagement blocks, lead magnets, profile alignment, and countable homework (not vague “post more”).

## Contents

| File | Purpose |
|------|---------|
| `SKILL.md` | Main skill: stance, session flow, extraction moves, content rules, playbooks, ethics, checklist |
| `references/frameworks.md` | Progressive disclosure: time split, trackers, habits, hooks, platform notes, nurture, etc. |

## Use in Cursor

1. Repo path: `.cursor/skills/linkedin-growth-coach/`
2. Ask the agent to follow this skill when you want LinkedIn coaching, post teardowns, or weekly execution plans.

Cursor discovers skills under `.cursor/skills/` per project.

Pipeline over vanity metrics, hooks and carousels, outreach scripts, broad/narrow/niche planning, 30-day trackers, wrong-audience viral fixes, employer vs personal brand balance, stigma niches, viral follow-ups, AI-assisted drafting workflows, low engagement diagnostics.
