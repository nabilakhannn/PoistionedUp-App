# PositionedUp Deployment Runbook

One-page guide to get the full system running: API + Frontend + Agent Runtime.

## Prerequisites

- Hostinger VPS with SSH access (root or sudo)
- Domain `agents.positionedup.com` pointed to VPS IP (optional, for HTTPS)
- OpenAI API key
- Telegram Bot token (optional, from @BotFather)
- Git repo access

## Quick Start (5 steps)

### Step 1: Setup VPS (one-time)

```bash
# Upload and run the setup script
scp deploy/setup-vps.sh root@YOUR_VPS_IP:/root/
ssh root@YOUR_VPS_IP
bash setup-vps.sh
```

This script:
- Installs Docker, enables firewall (UFW), configures Fail2ban
- Generates `OPENCLAW_GATEWAY_TOKEN` and `AGENT_API_KEY`
- Creates directory structure at `/opt/openclaw/`
- Prints the generated tokens — **save them**

### Step 2: Configure VPS Environment

```bash
# On the VPS
nano /opt/openclaw/.env
```

Fill in (the setup script creates a template):

| Variable | Required | Where to get it |
|----------|----------|-----------------|
| `OPENCLAW_GATEWAY_TOKEN` | Yes | Auto-generated by setup-vps.sh |
| `OPENAI_API_KEY` | Yes | OpenAI dashboard |
| `AGENT_API_KEY` | Yes | Auto-generated by setup-vps.sh |
| `TELEGRAM_BOT_TOKEN` | Optional | @BotFather on Telegram |
| `TELEGRAM_OWNER_CHAT_ID` | Optional | @userinfobot on Telegram |
| `POSITIONEDUP_API_URL` | Yes | Your deployed API (e.g. Vercel URL) |
| `POSITIONEDUP_USER_ID` | Yes | Your Supabase user ID |

### Step 3: Deploy Agent Runtime

```bash
# On the VPS
cd /opt/openclaw
git clone YOUR_REPO_URL app
cd app

# Build and start
docker compose -f deploy/docker-compose.yml up -d --build

# Verify
bash deploy/verify-deployment.sh
```

Expected output: all checks pass, gateway healthy on port 18789.

### Step 4: Connect Backend to Gateway

Add to your **backend** `.env` (local or Vercel):

```bash
OPENCLAW_GATEWAY_URL=http://YOUR_VPS_IP:18789
OPENCLAW_GATEWAY_TOKEN=<token from step 1>
AGENT_API_KEY=<key from step 1>
```

Or use SSH tunnel for local dev:
```bash
ssh -N -L 18789:127.0.0.1:18789 root@YOUR_VPS_IP
# Then use: OPENCLAW_GATEWAY_URL=http://localhost:18789
```

### Step 5: Verify Everything

1. Open `/mission-control/gateway` — should show ONLINE with green status
2. Open `/mission-control/chat` — select Jumbo, send "Hello"
3. Check Telegram (if configured) — bot should respond

## Local Development (no VPS needed)

Add to your `.env`:
```bash
OPENCLAW_MOCK_MODE=true
```

This enables demo mode:
- Gateway dashboard shows mock healthy status with DEMO MODE badge
- Chat console returns realistic mock agent responses
- All 6 agents appear with their real personas
- No network calls to any VPS

## HTTPS Setup (optional)

If you want `https://agents.positionedup.com`:

```bash
# On VPS
# 1. Point DNS A record to VPS IP
# 2. Open ports
ufw allow 80
ufw allow 443

# 3. Start with HTTPS profile
cd /opt/openclaw/app
OPENCLAW_DOMAIN=agents.positionedup.com docker compose -f deploy/docker-compose.yml --profile https up -d
```

Caddy auto-provisions Let's Encrypt certificates.

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Gateway dashboard shows OFFLINE | Check VPS is running: `docker ps` on VPS |
| "Connection refused" in health check | Gateway not started or firewall blocking port |
| 401 on gateway endpoints | `OPENCLAW_GATEWAY_TOKEN` doesn't match between API and VPS |
| Chat returns "Cannot reach gateway" | Check `OPENCLAW_GATEWAY_URL` in backend .env |
| Agents show "unknown" status | Gateway is up but agents haven't sent heartbeat yet |
| Telegram bot not responding | Check `TELEGRAM_BOT_TOKEN` and `TELEGRAM_OWNER_CHAT_ID` in VPS .env |
